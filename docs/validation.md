- 完整本地演示通过。执行入口：`npm run demo`。

- 自启动 MCP 测试验证了仅复用已认证服务、不接管未知端口、不停止其他服务及仅关闭自身创建的服务。
- 已在本机写入启用的 `cityline_single` Codex 配置，配置仅引用私有环境文件。通过该配置的实际启动命令完成握手、发现四个工具并跑完完整模拟；不等于当前已打开的聊天已经热加载这些工具。
- 已读取官方活动页面画面；2026年10月27日页面仍显示开放倒计时，未获得真实抽签表单的操作证据。

## 未验证及部署前提

- 没有在本次 Cityline 实际账号和抽签表单完成端到端实测。页面配置仍为 `verified:false`，真实选择器与账号、报名地址留空。
- 未确认本次表单接受美国 +1 或 DuoPlus 虚拟号码；未确认后续短信能送达。
- 按用户本次选择，仅接入本机 Codex；未创建或连接 ChatGPT 自定义 GPT，未提供公开 HTTPS 服务。
- GitHub 发布状态以仓库中的实际文件及提交为准，不能由本机源码包或本验证记录推断。
- 真实驱动默认限制所有 HTTP 请求为 Cityline HTTPS。第三方 CDN 或图形验证资源可能因此无法加载，需要实际页面核对后的专门适配；不应为使页面加载而直接取消限制。
- `completed` 与 `evidence.source=user_reported` 仅表示记录了用户提供的邮件编号，不能作为程序独立核验官方邮件的证明。
