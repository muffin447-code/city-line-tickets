# 验证范围

记录日期：2026年10月28日。本轮最终完整复测60/60通过，其中35项为浏览器离线替身测试；后续修改须以新的运行摘要为准。

## 程序及本机集成

- 已有完整测试与本地演示的成功记录，执行入口分别为 `npm test` 与 `npm run demo`。完整复测在允许监听本机端口的环境执行；端口权限错误不作为业务逻辑通过的证据。
- 集成测试启动真实 MCP 子进程，通过标准输入输出 JSON-RPC 调用真实本机 HTTP 服务，走过模拟注册、人工步骤接手、当前建号／登记提交确认及邮件编号记录。
- 演示与测试使用虚构资料，不访问 Cityline，不创建真实账号，不发真实短信或邮件，不提交真实抽签。
- 浏览器驱动使用离线 Playwright 页面替身，覆盖未知配置拒绝启动、可见请求的来源规则、页面延迟、独立非建号 OTP、资料页新增人工步骤、变化后拒绝旧确认及会话丢失后停止重放。
- 新增回归覆盖账号配置独立于抽签配置、账号完成后等待并仅重试抽签阶段、丢失等待会话后不重新建号，以及静态邮箱 `accountEmailIdentity` 的核对与变化保护。
- 配置将普通导航开窗 `accountOpenDialog` 与实际发送 OTP 的 `accountSendOtp` 分开；前者也必须单独核实 `accountOpenDialogIsNonConsequential`，默认 false。相同的“登入”文案不能作为两种操作可互换的证据。
- 密码分支的边界是用户亲自完成新密码输入、确认和账号提交全过程；驱动只观察 `accountSuccess` 及同人 `accountIdentity`，不接收密码或代点最终账号提交。本轮全套复测包含已填密码、身份不匹配、晚出现密码页及不重复OTP等回归。
- 服务接口覆盖认证、资料遮蔽、同人任务复用、拒绝换人、一次性挑战、防并发续跑、OTP 不写入记录、运行中断恢复、独占资料目录锁及真实模式关闭开关。
- 自启动 MCP 覆盖仅复用已认证服务、不接管未知端口、不停止其他服务及仅关闭自身创建的服务。
- 已通过本机已配置的 Codex 实际启动命令完成过握手、发现四个工具及完整模拟；这不等于任一已经打开的聊天自动热加载了新工具。

完整回归入口：

```bash
node --test tests/*.test.mjs integrations/*.test.mjs
```

浏览器替身单独回归入口：

```bash
node --test tests/browser.test.mjs
```

## 尚未验收

- 程序没有完成本次 Cityline 实际账号注册与抽签登记的自动端到端实测。人工账号完成与该项验收必须分开。
- 未确认本次报名是否要求 Cityline 账号、接受美国 +1 或 DuoPlus 虚拟号，也未确认官方短信送达。
- 账号阶段无需提前配置 `ballotUrl`。账号完成后缺少抽签配置时会停在配置等待状态；仅原进程及原浏览器会话保留时可对同一任务只重试抽签阶段。重启或会话丢失仍须人工恢复，不能声称无缝重放。
- 当前按用户选择接入本机 Codex；没有创建或连接 ChatGPT 自定义 GPT，没有部署其公开 HTTPS API。GPT Actions 材料作为可选源码保留。
- GitHub 发布情况以实际仓库和提交记录为准，不能由本机源码包或本文推断。
- 默认浏览器路由接收规则为 Cityline HTTPS。经核实并明确开启 `allowTurnstileResources` 后，对实际进入拦截器的初始可见请求，才为当前 Cityline 页面下的组件脚本、子 iframe 及内部资源请求最小放行精确来源 `https://challenges.cloudflare.com`；未知 frame 或来源不匹配的可见请求被拒绝，主框架／新窗口另作 Cityline 范围核对与导航观察。该配置不改 CSP 或浏览器安全，不处理挑战 token，不代做人机验证，不构成真实 Turnstile 或完整登记通过的证据。
- Playwright 路由在重定向时可能只覆盖首 URL。导航提交后的观察／关闭也不是每跳请求前的出站隔离；离线测试不能证明本程序具备网络防火墙或完整重定向链隔离能力。[官方路由限制](https://playwright.dev/dotnet/docs/api/class-page#page-route)
- 其他第三方认证、CDN 或 CAPTCHA 资源仍可能需要核实后的专门适配；不得为使页面加载而直接取消限制。官方资源依据见 [Cloudflare CSP 说明](https://developers.cloudflare.com/turnstile/reference/content-security-policy/) 与 [客户端渲染说明](https://developers.cloudflare.com/turnstile/get-started/client-side-rendering/)。
- `completed` 且 `evidence.source=user_reported` 只表示记录了用户提供的邮件编号，不证明程序已独立读取和验证官方确认邮件。

## 测试环境

本机测试环境为 Node.js 24.22.1，项目声明 Node.js >=22。Playwright 依赖固定为已发布版本1.64.1；离线替身回归不要求启动或下载浏览器。

源码中的测试、服务、MCP 适配器和示例配置不需要参与者的真实姓名、生日、邮箱、号码或验证码。私密资料只应留在按用途配置的本地私有环境中，不进入公开文档和仓库。
